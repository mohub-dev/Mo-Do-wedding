# الرسائل الصوتية للعروسين — التصميم

## الهدف

إتاحة بطاقة عامة بعنوان «اترك رسالة صوتية للعروسين» ليُسجل الضيف رسالة لا تتجاوز 60 ثانية بعد إدخال اسمه. تُحفظ التسجيلات بشكل خاص، ويستمع إليها المشرف أو يحذفها من لوحة الإدارة.

## النطاق

- الاسم إلزامي قبل بدء الإرسال.
- يدعم العميل تسجيل WebM/Opus من واجهة `MediaRecorder`.
- مدة التسجيل القصوى 60 ثانية؛ يتوقف التسجيل تلقائيًا عند انتهائها.
- التخزين: ملفات الصوت في Cloudflare R2، والبيانات الوصفية في Cloudflare D1.
- لا توجد روابط عامة أو قائمة عامة للتسجيلات.

## البنية والبيانات

### Cloudflare

يُضاف binding باسم `VOICE_MESSAGES` إلى R2 في `wrangler.jsonc` وإلى واجهة `Env` في Worker. يُنشأ Bucket خاص باسم متفق عليه عند النشر، بينما يستخدم التطوير المحلي محاكي R2 الخاص بـ Wrangler.

### D1

ترحيل جديد ينشئ جدول `voice_messages`:

| الحقل | الغرض |
| --- | --- |
| `id` | معرّف عشوائي فريد للتسجيل |
| `guest_name` | اسم الضيف بعد التحقق والتنظيف |
| `object_key` | مفتاح ملف الصوت في R2 |
| `content_type` | صيغة الصوت المسموح بها |
| `size_bytes` | حجم الملف المقبول |
| `duration_seconds` | مدة أبلغ بها العميل، لا تتجاوز 60 |
| `created_at` | وقت الإرسال |

يفهرس الجدول بحسب وقت الإنشاء لعرض أحدث الرسائل أولًا.

## واجهات Worker

- `POST /api/voice-messages`: عام؛ يقبل `multipart/form-data` يحتوي الاسم والملف والمدة. يتحقق من الاسم، الصيغة، الحجم، والمدة، ويخزن الملف في R2 ثم بياناته في D1.
- `GET /api/voice-messages`: للمشرف فقط؛ يعيد بيانات القائمة دون روابط عامة.
- `GET /api/voice-messages/:id/audio`: للمشرف فقط؛ يقرأ الكائن من R2 ويبثه مع نوع المحتوى المناسب.
- `DELETE /api/voice-messages/:id`: للمشرف فقط؛ يحذف ملف R2 وسجل D1. إن فشل حذف الملف، لا يُزال السجل حتى يمكن إعادة المحاولة بأمان.

تطبق الواجهات العامة فحص الأصل الحالي وتحديد معدل الإرسال. ترفض البيانات غير المطابقة قبل إنشاء أي كائن.

## واجهة الضيف

يضاف مكوّن `VoiceMessageCard` بعد دفتر التهاني. يقدم الحالات التالية:

1. إدخال الاسم وزر بدء التسجيل.
2. تسجيل نشط مع مؤقت تنازلي وزر إيقاف.
3. معاينة التسجيل مع إعادة التسجيل أو الإرسال.
4. رفع جارٍ، ثم نجاح أو خطأ قابل لإعادة المحاولة.

عند رفض إذن الميكروفون أو غياب دعم `MediaRecorder`، تعرض البطاقة شرحًا عربيًا واضحًا. لا يُرسل أي ملف بلا اسم، ولا يُتاح زر الإرسال حتى يتوفر تسجيل صالح.

## لوحة الإدارة

يضاف تبويب «الرسائل الصوتية» إلى لوحة الإدارة. لكل رسالة يعرض الاسم والتاريخ والمدة ومشغّل الصوت وزر حذف مع تأكيد. يجلب المشغّل الملف عبر مسار الإدارة المحمي، لا عبر رابط R2 مباشر.

## الأخطاء والاتساق

- عند خطأ R2 لا يُنشأ سجل D1.
- عند فشل إدخال D1 بعد رفع R2، يحذف Worker الكائن الذي رفعه قبل إعادة الخطأ.
- يتحقق العميل من الحد الزمني لتحسين التجربة؛ ويتحقق الخادم من القيمة والحد الأقصى للحجم للحماية.
- يبقى التسجيل محليًا في صفحة الضيف عند فشل الرفع حتى يستطيع إعادة المحاولة أو التسجيل من جديد.

## الاختبارات

- Worker: قبول تسجيل صالح؛ رفض الاسم الفارغ، المدة أو الحجم أو الصيغة غير المقبولة؛ حماية جميع مسارات الإدارة؛ والحذف المتسق من R2 وD1.
- العميل: منع البدء/الإرسال دون اسم أو تسجيل، الإيقاف التلقائي عند 60 ثانية، معالجة رفض الميكروفون، ومعالجة فشل الرفع.
- تكامل: يحفظ طلب صالح بياناته في D1 والكائن في R2، ويظهر في لوحة الإدارة ويُحذف منها.
